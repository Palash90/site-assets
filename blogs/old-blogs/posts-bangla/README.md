# লিনাক্স বাংলা গাইড — recovered posts

16 Bangla posts from the old Blogger blog **লিনাক্স বাংলা গাইড** (`linux.palash90.in`),
recovered in full from its Atom feed archived by the Wayback Machine (snapshot
`2017-12-03`, site itself long dead).

- **Source:** `web.archive.org/web/20171203233337/...feeds/posts/default` — the feed
  contained the *complete* blog with full HTML bodies, so no page-by-page crawling
  needed (unlike the English recovery in `../posts/`)
- **Era:** `bc` series Jul 2016; foundations & command-line series May 2017
- **Ordering:** files are numbered `01–16` following the guide's pedagogical flow
  (defaults to the feed's archive order; Blogger default slugs like
  `blog-post_9.html` were not descriptive, so English series slugs were reused —
  they are a post-for-post translation of the corresponding Unix/Linux series on
  `tech.palashkantikundu.in`)
- **Front matter:** each file has `title` (original Bangla), `date`,
  `original_url`, `recovered_from`
- **Terminal sessions** are preserved as fenced code blocks; 33 embedded images
  still point at `*.bp.blogspot.com` and are live
- **Converter:** `../../posts/` docs apply (`scrape_wayback.py` reused with a
  feed-based driver)
