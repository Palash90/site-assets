# Guitalele All Open Chords

These are the nine core open chord voicings in standard **A–D–G–C–E–A** guitalele tuning. Each section lists the exact strings, frets, and notes for the shape shown.

Read every shape from **low A → high A**: low A, D, G, C, E, high A. `0` means the string is played open, a number is the fret to press, and `x` means the string is muted or not played.

The Tab Viewer above sounds these exact voicings. The two alternate C Major voicings remain in the viewer; this gallery documents the nine main shapes.

## G Major

![G Major chord shape](${guitalele-g-major} "G Major chord shape")

- **Shape:** `xx0232` (low A → high A)
- **Fingered strings:** C string, 2nd fret → D · E string, 3rd fret → G · high A string, 2nd fret → B
- **Open strings:** G string → G
- **Muted / not played:** low A, D
- **Notes sounded:** G, D, G, B

The open G string and the 3rd-fret E string both sound G, so the root is doubled. The 2nd-fret high A string supplies B, the major third.

## D Major

![D Major chord shape](${guitalele-d-major} "D Major chord shape")

- **Shape:** `x02220` (low A → high A)
- **Fingered strings:** G string, 2nd fret → A · C string, 2nd fret → D · E string, 2nd fret → F#
- **Open strings:** D string → D · high A string → A
- **Muted / not played:** low A
- **Notes sounded:** D, A, D, F#, A

D is the lowest sounding note on the open D string, and A appears twice. The F# on the 2nd-fret E string is the major third that makes the chord major.

## A Major

![A Major chord shape](${guitalele-a-major} "A Major chord shape")

- **Shape:** `022100` (low A → high A)
- **Fingered strings:** D string, 2nd fret → E · G string, 2nd fret → A · C string, 1st fret → C#
- **Open strings:** low A string → A · E string → E · high A string → A
- **Muted / not played:** none
- **Notes sounded:** A, E, A, C#, E, A

All six strings sound. A is heard three times, E twice, and the C# on the 1st-fret C string is the major third.

## A Minor

![A Minor chord shape](${guitalele-a-minor} "A Minor chord shape")

- **Shape:** `022000` (low A → high A)
- **Fingered strings:** D string, 2nd fret → E · G string, 2nd fret → A
- **Open strings:** low A string → A · C string → C · E string → E · high A string → A
- **Muted / not played:** none
- **Notes sounded:** A, E, A, C, E, A

Only two strings are pressed. Compared with A Major, the C string changes from the 1st fret (C#) to open (C), which turns the major third into the minor third.

## D Minor

![D Minor chord shape](${guitalele-d-minor} "D Minor chord shape")

- **Shape:** `x02210` (low A → high A)
- **Fingered strings:** G string, 2nd fret → A · C string, 2nd fret → D · E string, 1st fret → F
- **Open strings:** D string → D · high A string → A
- **Muted / not played:** low A
- **Notes sounded:** D, A, D, F, A

The open D string gives the lowest note, while the F on the 1st-fret E string is the minor third. As in D Major, the low A string stays muted.

## G Minor

![G Minor chord shape](${guitalele-g-minor} "G Minor chord shape")

- **Shape:** `xx0231` (low A → high A)
- **Fingered strings:** C string, 2nd fret → D · E string, 3rd fret → G · high A string, 1st fret → A#
- **Open strings:** G string → G
- **Muted / not played:** low A, D
- **Notes sounded:** G, D, G, A#

The open G string and the 3rd-fret E string double the root. The A# on the 1st-fret high A string is the minor third that changes G Major into G Minor.

## F Major

![F Major chord shape](${guitalele-f-major} "F Major chord shape")

- **Shape:** `x32010` (low A → high A)
- **Fingered strings:** D string, 3rd fret → F · G string, 2nd fret → A · E string, 1st fret → F
- **Open strings:** C string → C · high A string → A
- **Muted / not played:** low A
- **Notes sounded:** F, A, C, F, A

The lowest sounding note is F on the 3rd-fret D string. F is also heard on the 1st-fret E string, while the open C string supplies the fifth.

## C Major

![C Major chord shape](${guitalele-c-major} "C Major chord shape")

- **Shape:** `320003` (low A → high A)
- **Fingered strings:** low A string, 3rd fret → C · D string, 2nd fret → E · high A string, 3rd fret → C
- **Open strings:** G string → G · C string → C · E string → E
- **Muted / not played:** none
- **Notes sounded:** C, E, G, C, E, C

All six strings sound. C appears three times, E twice, and G once. This is the only chord in this gallery where the low A string and the high A string are both fretted.

## E Minor

![E Minor chord shape](${guitalele-e-minor} "E Minor chord shape")

- **Shape:** `xx0432` (low A → high A)
- **Fingered strings:** C string, 4th fret → E · E string, 3rd fret → G · high A string, 2nd fret → B
- **Open strings:** G string → G
- **Muted / not played:** low A, D
- **Notes sounded:** G, E, G, B

The open G string and the 3rd-fret E string double the G, while the 2nd-fret high A string gives B. The root E is on the 4th fret of the C string.
