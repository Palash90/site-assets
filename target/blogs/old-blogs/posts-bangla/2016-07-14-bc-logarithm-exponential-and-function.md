আমরা দেখে নিয়েছি কিভাবে একটি সংখ্যাকে বিভিন্ন বেসে পরিবর্তন করতে হয়, আমরা কিছু সংখ্যাকে এক বেস থেকে অন্য বেসে পরিবর্তন করেছি। আমরা দেখে নিয়েছি কিভাবে আমরা বিভিন্ন ত্রিকোণমিতিক অপারেশন করতে পারি। আমরা দেখে নিয়েছি কিভাবে অভেদ এবং একটি মাত্র ত্রিকোণমিতিক অপেরেশনের সাহায্য নিয়ে অন্যান্য  ত্রিকোণমিতিক মান নির্ণয় করতে পারি। এবার আমরা জেনে নেবো কিভাবে লগারিদম এর মান বের করতে হয়। আবারও একটা কথা বলে দি, bc শুধুমাত্র ন্যাচারাল লগারিদম বা ln এর মান নির্ণয় করতে পারে, অন্য বেসের লগারিদম নির্ণয় করতে আমরা অভেদের সাহায্য নেবো, তাই এখানেও আমরা কয়েকটি অভেদ মাথায় রাখবো -

log <sub>y (x) = ln(x) / ln(y)

ln (e ^ x ) = x 

e ^ ln (x) = x

এবার আমরা কিছু উদাহরণ দিয়ে দেখে নেবো লগারিদম এবং এক্সপোনেনশিয়াল কিভাবে গণনা করা হয় -

এইভাবে কাজ করার সময়ে একটা অসুবিধার মধ্যে পড়তে হয়। যদি আমরা কোনো সূত্র বার বার রান করতে চাই বিভিন্ন মানের জন্যে তো, আমাদের বার বার কোনো একটি ভ্যারিয়েবলের (এই ক্ষেত্রে x )  মান বদলে আবার সূত্রটি রান করতে হয়। ছোটোখাটো হিসেবের ক্ষেত্রে ঠিকঠাক হলেও বড় সূত্রের ক্ষেত্রে সেটি খুবই অসুবিধার। তাই আমরা একটা নতুন পদ্ধতি শিখে নেবো কিভাবে এই রকম সমস্যার সমাধান করা যায় এবং আমরা প্রোগ্রামিংয়ে আর এক ধাপ এগিয়ে যাবো, দেখে নেবো কিভাবে function লিখতে হয় bc তে। খুব সহজ সরল ভাষায় function হলো একটি প্রোগ্রামিং ব্লক, যেখানে আমরা এক বা একাধিক লাইন প্রোগ্রাম একসাথে লিখে সেটিকে একটি নামে অভিহিত করবো এবং পরবর্তী সময়ে সেই নামের প্রোগ্রামটিকে ইনপুট দিলে, সেটি আমাদের প্রয়োজনীয় আউটপুট দেবে। এবার আমরা দেখে নেবো কিভাবে function লিখে সেটিকে ইনপুট দিতে হয় -

```
define log(x){ return l(x)/l(10); }

log(10000)

define log(x, y){ return l(y)/l(x); }

.09999999999999999999

```

একটু ভালো করে পড়লেই বুঝতে পারবেন function টি কি কাজ করছে। প্রথম ক্ষেত্রে এটি একটি মান নিয়ে সেটার log base ১০ মান নির্ণয় করছে।
পরে সেই function টিকে পরিবর্তন করে আরো একটি মান ইনপুট দিচ্ছি আমরা এবং পরিবর্তিত  function টি log <sub>x (y) এর মান গণনা করছে।
এবার ভালোভাবে শেষ লাইনটি লক্ষ্য করুন, আমরা যখন function টি পরিবর্তন করলাম তখন আর মাত্র একটি মান ইনপুট দিলে সেটি কাজ করছে না, কারণ এখন function টি দুটি মান ইনপুট হিসেবে নিচ্ছে, এই মান গুলিকে প্রোগ্রামিংয়ের ভাষায় parameter বলা হয়। এবার ভেবে দেখুন, ত্রিকোণমিতিক অপারেশন গুলি কত সুন্দর ভাবে আমরা function এর সাহায্যে লিখে ব্যবহার করতে পারতাম। আমি এখানে সেগুলি আপনার জন্যে করবো না। এই কাজটা আপনার জন্যে রইলো, ত্রিকোণমিতির সূত্রগুলি নিজের সুবিধামত  function এর আকারে প্রকাশ করে সেগুলিকে ব্যবহার করা।

function লেখার পরে কাজ অনেক সহজ হলেও আপনি একটা জিনিস খেয়াল করবেন যে, যখন আপনি bc থেকে বেরিয়ে আসবেন এবং আবার bc টাইপ করে  তাতে গণণার কাজ করবেন, তখন আপনার আগের বারের লেখা function গুলি হারিয়ে যাবে। আপনার নিশ্চয় ইচ্ছা হচ্ছে আপনার সমস্ত সূত্র গুলি সেভ করে রাখতে এবং পরবর্তী কালে সেগুলি ব্যবহার করতে।

কিন্তু সেটার জন্যে আপনাকে লিনাক্সের এডিটর এবং ন্যূনতম ফাইল সিস্টেমের ধারণা রাখতে হবে। আপনার যদি এই সমস্ত সম্পর্কে ধারণা থাকে তাহলে আপনি এগিয়ে যেতে পারেন পরবর্তী অংশে - [bc - ফাইল এবং প্রোগ্রামিং](http://linux.palash90.in/2016/06/bc.html)
